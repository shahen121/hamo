# هدية غامارد — ليلة نهائي مونديال 26

موقع بسيط بصفحة وحدة: الزبون يسكن QR ع الطاولة → يشوف هدية غامارد → يتابع الانستقرام → يرجع تنفتح الهدية → يكتب رقم الطاولة → الطلب يوصل فوراً كإشعار تيليجرام على موبايل المطعم.

## محتويات المشروع

```
gamarde-worldcup-gift/
├── index.html         الصفحة الرئيسية
├── style.css           التصميم
├── script.js            منطق الفتح والإرسال
├── worker.js             كود الـ Cloudflare Worker (وسيط تيليجرام)
├── generate-qr.html    أداة لتوليد QR بعد ما يصير الموقع لايف
└── README.md            هاي الصفحة
```

---

## الخطوة 1 — نشر الموقع على GitHub Pages

1. سوّي repository جديد بحسابك على GitHub (مثلاً باسم `gamarde-worldcup-gift`).
2. ارفع الملفات الأربعة: `index.html`, `style.css`, `script.js`, `generate-qr.html`.
   - أسهل طريقة: اسحب الملفات مباشرة بصفحة الـ repo على GitHub (Add file → Upload files).
3. روح لـ **Settings → Pages**.
4. تحت **Branch** اختار `main` والمجلد `/root`، واضغط **Save**.
5. بعد دقيقة-دقيقتين رح يظهرلك رابط الموقع شكله:
   `https://username.github.io/gamarde-worldcup-gift/`

هاد الرابط هو يلي رح تحطه بالـ QR.

---

## الخطوة 2 — إنشاء بوت تيليجرام

1. افتح تيليجرام ودوّر عن **@BotFather**.
2. ابعتله `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ `bot`).
3. رح يعطيك **توكن** شكله تقريباً:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   → احتفظ فيه، رح تحتاجه بالخطوة الجاية.
4. لحتى تحصل على **Chat ID** (رقم الشات يلي رح توصله الإشعارات):
   - ابعت أي رسالة لبوتك الجديد (أو ضيفه لقروب تيليجرام خاص بالمطعم).
   - افتح بالمتصفح:
     `https://api.telegram.org/bot<التوكن>/getUpdates`
   - رح تشوف بالنتيجة رقم `"chat":{"id": ...}` — هاد هو الـ Chat ID.
   - (إذا القروب، الرقم رح يكون سالب متل `-1001234567890` — طبيعي، خذه متل ما هو).

💡 نصيحة: سوّي قروب تيليجرام خاص بموظفين المطعم (المضيف/الكابتن)، وضيف البوت إله. هيك كل الطلبات توصل لكل الفريق مو لموبايل واحد بس.

---

## الخطوة 3 — نشر الـ Worker (الوسيط الآمن لتيليجرام)

ليش لازم Worker؟ لأنه ما فينا نحط توكن البوت مباشرة بكود الموقع (أي حدا يقدر يشوفه ويسيء استخدام البوت). الـ Worker يخزن التوكن بأمان وبعدين يبعت الرسالة نيابة عن الموقع.

1. سوّي حساب مجاني على [cloudflare.com](https://cloudflare.com) إذا ما عندك.
2. من الداشبورد: **Workers & Pages → Create → Create Worker**.
3. اختار اسم (مثلاً `gamarde-gift-relay`) واضغط **Deploy**.
4. اضغط **Edit code**، امسح الكود الافتراضي، والصق فيه محتوى ملف `worker.js` كامل.
5. اضغط **Deploy** فوق.
6. روح لـ **Settings → Variables and Secrets** بنفس الـ Worker، وضيف:
   - `TELEGRAM_BOT_TOKEN` → التوكن يلي أخذته من BotFather (اختار Type = Secret)
   - `TELEGRAM_CHAT_ID` → الـ Chat ID يلي حصلته
   - (اختياري) `ALLOWED_ORIGIN` → رابط موقعك بالـ GitHub Pages، لحماية إضافية
7. احفظ، وخذ رابط الـ Worker من فوق الصفحة، شكله:
   `https://gamarde-gift-relay.YOUR-SUBDOMAIN.workers.dev`

   رح تحتاج تضيف `/order` بآخره لما تحطه بالموقع (شوف الخطوة الجاية).

---

## الخطوة 4 — ربط الموقع بالـ Worker

1. افتح `script.js`.
2. لاقي هاد السطر بالأعلى:
   ```js
   const WORKER_URL = "https://YOUR-WORKER-NAME.YOUR-SUBDOMAIN.workers.dev/order";
   ```
3. بدّله برابط الـ Worker الحقيقي يلي أخذته بالخطوة السابقة (مع `/order` بالآخر).
4. ارفع النسخة المعدّلة من `script.js` على GitHub (تعديل مباشر بالمتصفح كافي: افتح الملف بالـ repo → أيقونة القلم → Commit).

## الخطوة 5 — التخصيص قبل الإطلاق

بالملفات الحالية في نصوص مؤقتة (placeholders) لازم تبدّلها:

| وين | شنو تبدّل |
|---|---|
| `index.html` | كل مكان مكتوب `[اسم المطعم]` (3 أماكن) |
| `index.html` → `igFollowBtn` | رابط `href="https://instagram.com/gamarde"` بدّله لرابط حساب انستقرام الصحيح |
| `index.html` → `gift-grid` | حالياً في 3 بطاقات بأشكال هندسية بديلة (placeholder) — بدّل الـ `.gift-image` بصور حقيقية لمنتجات غامارد (احفظ الصور بمجلد `assets/` واستبدل الـ `<div class="gift-image">` بـ `<img src="assets/product1.jpg">`) |
| `worker.js` | ما في شي لازم يتبدل بالكود نفسه، بس تأكد الـ Secrets مضافة صح |

## الخطوة 6 — توليد وطباعة QR

1. بعد ما يصير الموقع لايف على GitHub Pages، افتح `generate-qr.html` (تقدر تفتحه مباشرة من رابط GitHub Pages: `.../generate-qr.html`).
2. حط رابط موقعك بالحقل.
3. اضغط **تحميل QR** واطبعه، حطه على استاند صغير بكل طاولة.

---

## اختبار سريع قبل الافتتاح

- افتح رابط الموقع من موبايلك (مو من الكمبيوتر، حتى تجرب تجربة QR الحقيقية).
- اضغط "تابعنا على انستقرام"، رجع عالمتصفح، وتأكد الهدية تنفتح تلقائياً.
- إذا ما انفتحت تلقائياً (بيصير بمتصفحات معينة)، جرب زر "رجعت توي؟ افتح الهدية يدوياً".
- اكتب رقم طاولة وابعت، وتأكد الرسالة توصل فعلاً على تيليجرام خلال ثواني.

## ملاحظات

- ما في قاعدة بيانات — كل طلب يوصل كرسالة تيليجرام بس. إذا حبيت تحتفظ بسجل، ممكن نضيف لاحقاً كتابة كل طلب بجدول Google Sheets كمان بنفس الـ Worker.
- التصميم الحالي لمطعم واحد. إذا قررت تتوسع لأكثر من فرع بالمستقبل، بنعدل الموقع ياخذ رمز/رقم فرع من رابط الـ QR نفسه (مثال: `?branch=karrada`) ويرسله مع الطلب، حتى تعرف الطلب جاي من وين.
